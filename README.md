# 🎓 Student Performance System

A terminal-based Python application with a MariaDB / MySQL database backend to manage student records, validate inputs, calculate grades, and generate class performance summaries.

---

## ✨ Features
* **[1] Add Students**: Inputs names, emails, and 3 grades (Preliminary, Midterm, Final) with strict validation checks and duplicate prevention.
* **[2] View Records**: Displays all students in a neat table with computed averages and status.
* **[3] Class Summary**: Calculates class averages, highest/lowest scores, and passing rates.
* **[4] Search Student**: Case-insensitive name lookup for individual student profiles.
* **[5] Edit Record**: Update specific student details or individual grades.
* **[6] Delete Record**: Secure removal of student entries with confirmation prompts.
* **[7] Exit**: Safely closes database connections.

---

## 🛠️ Tech Stack
* **Language**: Python 3
* **Database**: MariaDB / MySQL (`mysql-connector-python`)
* **Environment**: Android via Termux
